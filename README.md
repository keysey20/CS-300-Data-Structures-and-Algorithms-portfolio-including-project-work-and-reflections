# CS 300 Portfolio Reflection

The main problem I was solving in this course was how to efficiently store, organize, and retrieve course data using different data structures. In Project One, I analyzed the runtime and memory performance of a vector, hash table, and binary search tree. In Project Two, I implemented a program that loads course data from a file, sorts it in alphanumeric order, and allows users to search for specific course information.

I approached the problem by evaluating the strengths and weaknesses of each data structure. The vector was simple but inefficient for searching, with linear time complexity. The hash table provided fast lookup in constant time but did not maintain order. The binary search tree provided a balance by allowing efficient searching and automatically maintaining sorted data through in-order traversal. This showed me why choosing the right data structure is critical for performance and usability.

One challenge I faced was ensuring that the program correctly loaded, stored, and displayed the data in the correct order. I overcame this by testing each part of the program step by step and debugging issues with sorting and searching.

This project expanded my approach to software design by making me think more about efficiency before coding. I learned to choose data structures based on the problem instead of just using what is easiest. It also improved how I write programs by focusing on readability, organization, and modular design so the code is easier to maintain and update.

Overall, this experience helped me better understand how to design efficient programs and reinforced the importance of writing clean, structured, and adaptable code.
